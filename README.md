# Marine Image Evaluator

Python-инструмент оценки характеристик изображений водной поверхности. Основа - исследовательские скрипты Арсения Батуева для задачи Qoolo по подготовке изображений для обнаружения мусора в разных погодных условиях.

Программа вычисляет резкость, насыщенность, яркость, контраст, энтропию, спектральные характеристики и эвристические показатели области воды. Исходные сценарии также сравнивают серии кадров с SSIM и оптическим потоком. Опциональный модуль использует готовые IQA-модели через PyIQA.

## Быстрая демонстрация

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python create_demo.py
.venv/Scripts/python evaluate.py demo-images --output output
```

В Linux использовать `.venv/bin/python`. `create_demo.py` создаёт явно синтетические тестовые узоры; данные Qoolo для запуска не требуются.

Для своих изображений:

```powershell
python evaluate.py path/to/images --output output
```

Сканирование рекурсивное. Поддерживаются Unicode-пути в Windows, PNG/JPEG/WebP/BMP/TIFF; повреждённые изображения записываются в список ошибок. Результат: `results.csv` и `results.json` с относительными именами файлов. По умолчанию модели и их веса не загружаются.

## Интерпретация

Полученные показатели описывают изображение и заданные эвристики. Доля воды определяется простым приближением по цвету и текстуре. Эти значения сами по себе не подтверждают физическую корректность сцены или качество обучения детектора.

Основной CLI экспортирует вычисленные характеристики, исключая исходные поля с названием «экспертный MOS» и сводные рейтинги: они рассчитывались эвристически. Прирост mAP и сокращение ложных срабатываний в этом проекте не измеряются. Обучение модели обнаружения мусора не входит в описанный личный вклад.

Для дополнительного IQA установить `requirements-neural.txt` и передать `--neural`. Этот режим может загрузить веса сторонних моделей и требует отдельного времени и места. Основная демонстрация и проверки проходят без него.

## Исходные сценарии и проверки

`marine_metrics.py` содержит вычисления, `run_evaluation.py`, `marine_fog_evaluation.py` и `marine_pollution_evaluation.py` сохраняют исходные специализированные сценарии исследования. Для новой папки произвольных изображений удобнее `evaluate.py`.

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Проверки покрывают Unicode-имена, повреждённый файл, отсутствие приписанного человеческого MOS и совпадение кадров. Исходные отчёты, большие изображения компании и окружения разработки не включены в репозиторий.
